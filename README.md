# Júnior Santana | Advocacia Criminal

Landing page estática, pronta para publicação.

## Publicação

Envie todo o conteúdo desta pasta para a raiz do domínio em qualquer hospedagem de arquivos estáticos, como Netlify, Vercel, GitHub Pages ou hospedagem cPanel.

O arquivo de entrada é `index.html`. Não é necessário instalar Node.js, PHP ou banco de dados.

## Checklist pós-publicação

1. Publique em HTTPS.
2. Abra o site em desktop e celular.
3. Teste todos os botões de contato e confirme a abertura do WhatsApp.
4. Use o Google Tag Assistant para verificar `AW-18399510094`.
5. No Google Ads, confirme o recebimento do evento `AW-18399510094/nXedCOS7mfQcEM78yMVE`.
6. Quando o domínio definitivo existir, atualize o `robots.txt` e adicione um sitemap.

## Arquivos principais

- `index.html`: conteúdo, SEO básico, Google tag e conversão de contato.
- `styles.css`: estilos base.
- `hero-fix.css`: ajustes visuais das seções conforme as referências.
- Arquivos `.png`, `.jpg` e `.avif`: imagens utilizadas pela página.
